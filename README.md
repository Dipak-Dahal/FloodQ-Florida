# FloodQ Florida

FloodQ Florida is an experimental project exploring quantum-assisted hurricane evacuation planning. It combines interactive hazard visualization, evacuation route analysis, and quantum optimization to investigate safer evacuation options under changing storm conditions.

## Key Features
- Hurricane and flood-risk visualization
- Interactive Florida map and storm-track exploration
- Evacuation route analysis
- Qiskit-based optimization using the Quantum Approximate Optimization Algorithm (QAOA)
- Hybrid quantum-classical optimization experiments

## Technologies
Python, Qiskit, QAOA, JavaScript, HTML, and CSS.

## Limitations
FloodQ is an experimental prototype. Its hazard estimates and evacuation options depend on available data and modeling assumptions. It is not an official forecasting or emergency service.
